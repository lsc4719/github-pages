SQL · JDBC

Spring Start Here의 데이터 소스·JDBC 부분.

4주

트랜잭션

완료 상태 UPDATE와 변경 기록 INSERT를 한 서비스 메서드로 묶습니다. 두 쓰기 사이에 RuntimeException을 던집니다.

완료 · 서비스 빈을 외부에서 호출한 뒤 두 테이블 조회. 실패 시 두 변경이 모두 취소됨을 확인.

완료 · 전후 계획 2개. 인덱스 사용 여부를 데이터 선택도와 연결해 설명.

완료 · Java 코드와 실제 SQL 비교. 여유가 있으면 같은 트랜잭션 안의 변경 감지 확인.

8주

실패를 검증하고 재실행하기

테스트

Spring Start Here의 단위·통합 테스트 부분.
실습
빈 제목 거절·생성 후 조회·서비스 롤백을 테스트합니다. 앱·DB·테스트 실행법을 README에 적고 재실행합니다.

완료 · API 실행법과 테스트 결과. 롤백은 서비스 호출 뒤 새 DB 연결로 확인해 테스트 자체의 자동 롤백과 구분.

  • 읽기: 해당 주제의 절만 읽고 질문 하나를 적습니다.
  • 실행: 예제를 바꿔 실행하고 응답·SQL·로그 중 하나를 남깁니다.
  • 적용: 학습 기록 API에 적용한 뒤 자료를 닫고 3문장으로 설명합니다.

예시: 화 45분 · 목 45분 · 주말 90분. 본교재는 Spring Start Here, 보조 자료는 해당 주제의 공식 문서로 제한합니다.

진도가 밀리면

  • 바쁜 주: 20분씩 두 번. 질문 하나와 실행 결과 하나만 남깁니다.
  • 완료 기준 미달: 같은 주차를 연장합니다. 주 90분이면 각 주차를 2주로 나눕니다.
  • 30분 이상 막힘: 기대 결과·실제 결과·최소 코드나 SQL을 기록하고 다음 세션에서 이어갑니다.
  • 2주 후 조정: 예정 6회 중 3회 이하로 시작했다면 다음 주 분량을 절반으로 줄입니다.
